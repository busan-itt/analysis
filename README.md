# 부산 신항 환적 데이터 분석

**부산 신항의 선석 통합운영을 통한 환적 체류시간 저감** 프로젝트의 분석 저장소입니다.

자부두·타부두 환적 데이터의 특성을 살펴보고, 환적 과정과 야드 체류시간, 선박 운영시간의 관계를 분석합니다.

[프로젝트 소개](https://github.com/busan-itt) · [데이터 저장소](https://github.com/busan-itt/data) · [시뮬레이션](https://github.com/busan-itt/simulation)

## 권장 확인 순서

1. **EDA**에서 데이터 구성, 결측치와 변수의 의미를 확인합니다.
2. **분석 레포트**에서 대상별 환적 과정과 시간 지표를 살펴봅니다.

## 노트북 열람 및 재실행

GitHub에서 각 노트북을 열어 저장된 설명, 표와 그래프를 확인할 수 있습니다. 코드를 재실행하려면 Jupyter Notebook 또는 JupyterLab 등에서 파일을 열어 주세요.

- 노트북별로 사용하는 입력 파일명과 경로를 확인하고 실행 환경에 맞게 설정합니다.
- 일부 노트북은 별도의 선석스케줄 CSV, 컨테이너 상세 가공 파일 등 추가 입력을 사용합니다. 데이터 저장소의 원본과 가공 과정·컬럼 구성을 확인해 준비해야 합니다.
- 홍성진 레포트는 `DGT_SELF_TS.csv` 등 추가 입력을 사용합니다. 연간 컨테이너 출입 자료의 파일명도 현재 저장소와 다르므로, 재실행 전 입력 파일과 경로를 확인해 주세요.
- 필요한 라이브러리는 각 노트북의 불러오기 구문을 기준으로 설치합니다.

## 결과 해석

야드 체류시간과 전체 환적 소요시간은 포함하는 공정이 다릅니다. 결과를 비교할 때는 각 노트북의 시간 정의, 분석 대상과 전처리 조건을 함께 확인해 주세요. 관측 데이터에서 나타난 상관관계만으로 인과관계를 단정하지 않습니다.
